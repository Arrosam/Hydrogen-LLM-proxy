# Hydrogen v2.3.0-preview.1

Channel: **preview**. Local integration candidate; publication and deployment have not occurred. Existing stable/latest release and image pointers must remain unchanged.

This preview combines declared server-tool availability and frozen session policy, a searchable hosted-tool binding combobox, read-only per-service MCP discovery, strict local mismatch fallback, independent OCR/ASR requests, durable pending-adapter execution and the shared parameter override fieldset styling.

## Behavior and migration

- Clients must explicitly declare each Hydrogen server tool; bindings describe availability. Ordinary client functions stay client-owned. The default emitted prefix is `provider_server_side_`, and an explicit empty prefix is valid.
- Model Service policy is an exact-name blacklist/whitelist. Each upstream step inherits or replaces the whole policy in Advanced. Micro Agent does not duplicate that editor.
- Supported saved Responses/conversation identities retain their stored configuration and executor ownership. Historical sessions without snapshots require a new session (409); the owner's historical-session approval remains unresolved. Stateless history resends cannot claim frozen identity.
- Existing Keys may initialize/list a scoped service's live discovery catalog. Every page uses current configuration and may duplicate/omit entries during edits. Calls are unsupported. Conflicting same-name definitions return `catalog_conflict`; administrators resolve the ambiguity. Whitelisted upstream tools use explicitly unverified placeholder schemas.
- Typed local tool mismatches skip retry/backoff and advance to the next sequential stage. Actual provider errors retain ordinary retry behavior. Saved pending operations use private durable claims/receipts to prevent replay; an unknown outcome stays terminal. OCR/ASR use independent internal requests with no caller tool leakage; ASR forwards configured language/prompt.
- The combobox preserves numeric IDs, disabled/missing bindings, removable chips and atomic 64-binding limits. Stage Parameter overrides shares the existing outlined fieldset style.

F002 model filtering is not implemented. No production data, real adapters or paid providers are needed for verification.

Actual publication remains a separate action after the exact commit and verification report are presented.
