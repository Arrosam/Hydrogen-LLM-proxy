# Hydrogen v2.2.2

This patch release improves Model Service and Micro Agent configuration, fixes a mixed-reasoning streaming decoder failure, and adds safe copying and in-place model mapping editing.

## Advanced settings and thinking processing

- Groups **Thinking**, **Hosted server tools**, and **Attachments** in a collapsible **Advanced** section while keeping the main service workflow visible.
- Adds a prominent Thinking On/Off switch with neutral styling consistent with the surrounding controls. Output format, per-upstream decoder settings, and parser guidance appear only while processing is on.
- **Off** saves `thinkingProcessing: false`: inline thinking remains ordinary text, including unterminated tags, and the saved output format does not rewrite client presentation. Native structured reasoning remains available through the wire adapter.
- Propagates an explicit Micro Agent off setting through referenced Model Services, nested agents, inline stages, and OCR calls without modifying reused child definitions.
- Retains parser settings across off/on, preserves configured values when Advanced is collapsed, and recognizes existing decoder-only configurations on unrelated saves.
- Updates English/Chinese guidance and switch/decoder accessibility labels. The separate generation-level `thinking: "disabled"` control retains its existing behavior.

## Streaming decoder fix

- Handles Chat Completions stream frames containing native `reasoning_content` or `reasoning` together with answer content by emitting native reasoning first, matching buffered parsing.
- Prevents literal `<think>` tags in that same-frame answer from being misclassified as a second thinking channel and triggering “Upstream thinking block was interrupted.”
- Covers buffered JSON, buffered SSE, streaming relay, and reliable streaming; genuine later-frame structural interruptions still retain their explicit error behavior.
- This fixes the reproduced mixed-field case, not arbitrary unconfigured provider-specific inline grammars.

## Copy Model Services and Micro Agents

- Adds **Copy** to both Model Service and Micro Agent cards, with a unique suggested name, name validation, and recoverable error handling.
- Copies the saved definition directly, preserving nested references, legacy fields, overrides, retry settings, description, and enabled state rather than reconstructing it through the visual editor.
- Leaves the original service and all existing references unchanged. Referenced services are not recursively cloned.
- Administrators can copy hosted-tool bindings. Non-admin copies omit those bindings with an explicit warning.

## Edit model mappings in place

- Adds **Edit** to existing provider mappings, allowing the upstream model ID, integer priority, and enabled state to be updated.
- PATCHes the existing mapping row instead of deleting and recreating it. Model/provider identity and format allowlists remain unchanged, preserving Model Service references.
- Accepts upstream IDs missing from provider discovery and retains input after save failures.
- Warns that disabling a mapping makes it unavailable to services that use it. New mapping creation remains unchanged.

## Compatibility

- No database migration or new provider/service category is required.
- Definitions without `thinkingProcessing` retain existing runtime behavior; the editor preserves active legacy decoders and original presentation.
- Runtime requirements remain Node 22.12+; the container uses Node 22.
- The previously published v2.2.1 tag and release are preserved.
