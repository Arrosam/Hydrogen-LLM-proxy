# Hydrogen v2.3.0-preview.2

Channel: **preview**. This is the revised aggregate candidate after dependency remediation. The earlier preview.1 was tested and tagged locally only; it was never published remotely. Existing stable/latest release and image pointers remain outside this preview.

This release combines declared server-tool policy and frozen snapshot-bearing sessions, the hosted-tool combobox, read-only live MCP discovery, strict local mismatch fallback, independent OCR/ASR requests, durable pending adapters, shared parameter override fieldsets and aggregate ownership/narrow-layout fixes.

## Behavior and migration

- Clients explicitly declare Hydrogen server tools; bindings describe availability. Ordinary functions stay client-owned. The emitted prefix defaults to `provider_server_side_`; explicit empty remains valid.
- Model Service policies are exact-name blacklist/whitelists. Each step inherits or replaces the whole policy in Advanced. Micro Agent has no duplicate policy editor.
- Snapshot-bearing saved Responses/conversation sessions retain their stored configuration and executor ownership. Historical used identities without snapshots return native 409 and require a new session; records are retained. The owner explicitly accepted this exception. An unused conversation can capture its initial configuration. Stateless history cannot claim frozen identity.
- Discovery is read-only and current on every page. Calls are unsupported; same-name conflicting schemas return `catalog_conflict`. Whitelisted upstream placeholder schemas remain explicitly unverified. Edits can duplicate/omit entries across pages; no discovery snapshot is promised.
- Typed local mismatches advance to the next stage without retry/backoff. Actual upstream retry remains. Durable private claims/receipts prevent pending adapter replay. OCR/ASR are independent ordinary internal requests without caller tools; ASR retains configured language/prompt.
- Aggregate fixes preserve client-owned calls despite reused provider IDs. Narrow modal actions and binding-limit errors remain accessible through repeated/interrupted interactions.
- Tailwind and its PostCSS adapter are pinned to 4.3.3, removing one inherited braces advisory propagated through five package records. Existing dashboard colors/control styling are retained. Supported browsers are **Safari 16.4+, Chrome 111+ and Firefox 128+**. No dependency gate is waived.

F002 model filtering is not implemented. No production deployment, database access, paid provider or OAuth scope expansion is included.

## Verification and channel isolation

Root/server/web package and lock metadata are `2.3.0-preview.2`; matching tag is `v2.3.0-preview.2`. Full tests, typecheck/build, strict fixtures, unfiltered audit, synthetic HTTP/MCP scenarios, independent code/ISTQB and real desktop/narrow browser validation must be pinned to the final commit. The published image is pulled by digest and smoke-tested with disposable data before publication is reported complete. No stable/latest pointer is emitted and no production instance is deployed.
