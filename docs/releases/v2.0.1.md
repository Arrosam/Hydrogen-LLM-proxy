# Hydrogen v2.0.1

这是一个修复版本，解决了在 HTTPS 反向代理后，API Key 页面「复制密钥」按钮返回 `415 Unsupported Media Type` 的问题。

## 修复

- **复制已签发的 API Key**：控制台的所有写操作（`POST`/`PUT`/`PATCH`）现在都会显式携带 `Content-Type: application/json` 与一个 JSON 请求体。此前「复制密钥」发出的是一个既没有请求体、也没有 `Content-Type` 的裸 `POST`，部分前置反向代理会以 `415 Unsupported Media Type` 拒绝它；新建密钥不受影响，因为它本就带有 JSON 请求体。
- 退出登录、重启升级等同样没有请求体的写操作一并修复。
- 该问题由 v2.0.0 引入：为把密钥移出中间层访问日志，重新显示密钥的接口从 `GET` 改为 `POST`，但请求体一直是空的。

## 升级与兼容性

- 无数据库变更，可直接在 2.0.0 之上替换镜像。
- 升级后请硬刷新一次浏览器，确保加载新的前端资源。

- 59 个测试文件、980 项测试通过。
- 服务端与前端 TypeScript 检查、生产构建通过。
