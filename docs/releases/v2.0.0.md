# Hydrogen v2.0.0

Hydrogen 2.0 引入有状态 Responses 与服务器托管 HTTP 工具。开发者可以通过自己的工具转接服务，为不同模型供应商提供统一的服务器工具能力。

## 新功能

- **Responses 会话状态**：支持 `previous_response_id` 续接、响应查询与删除、Conversations 和会话条目管理。所有历史按 API Key 隔离。
- **后台执行与取消**：支持 `background:true`、状态查询和取消 API；流式事件可通过 `starting_after` 恢复读取。
- **服务器托管工具**：管理员注册工具并绑定 Model Service 或 Micro Agent。Hydrogen 自动提供工具定义，复用 Micro Agent 的执行机制，完成模型与工具之间的循环。
- **HTTP 调用编辑器**：配置 POST URL、加密认证头、参数 JSON Schema、JSON 请求模板和结果 JSON Pointer；可预览参数与结果映射。工具业务逻辑由外部 HTTP 服务实现。
- **Responses / Anthropic 接入**：任意命名工具使用 Hydrogen 扩展记录调用过程。混合托管工具和客户端工具时，先执行托管工具，再返回客户端调用；Anthropic 可用 `hydrogen.previous_response_id` 续接。
- **三种流式方式**：每个服务可选择全部模型轮次与工具事件、工具进度与最终答案，或仅最终答案，并设置工具调用上限。Micro Agent 阶段共享顶层调用预算。
- **历史与备份管理**：设置页可调整历史保留期；备份支持工具配置、绑定和响应历史，工具认证头可跨主密钥安全恢复。

本正式版也包含此前 1.8.0 候选版本的 Model Bench、thinking 输出格式控制、输入/输出 token 明细、供应商代理路由，以及协议转换、空白响应处理和安全修复。

## 升级与兼容性

- 首次启动自动应用新增的 SQLite 迁移。升级前建议备份数据库和主密钥；数据库迁移后不应直接用旧版程序运行同一数据目录。
- Responses 默认保存历史，闲置保留期默认为 30 天；可在设置页修改，`0` 表示永久保留。`store:false` 的响应不保留供后续查询或续接，后台任务要求 `store:true`。显式 Conversations 独立保留。
- 工具 HTTP 错误作为工具结果交回模型；HTTP 层不自动重试。进程重启或备份恢复后，未完成的后台任务标记失败，不会自动重发工具操作。单个 SQLite 数据目录应由一个 Hydrogen 进程使用。
- 工具调用记录采用 Hydrogen 扩展，并非厂商专用内置工具类型；完整接入示例和支持范围见下方文档。
