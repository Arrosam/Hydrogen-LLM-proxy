# Hydrogen v2.1.1

补丁版本：进一步降低带图（尤其带 OCR 预处理的）请求的瞬时内存，并重发镜像。

## 优化

- **图片哈希不再把整张图解码成一个 Buffer**。OCR 缓存的内容寻址以前会把每张图的 base64 一次性解码（一张 25 MB 的图约等于 18 MB 的 Buffer），多个并发叠加起来很可观。现在按 256 KiB、4 字符对齐的分片增量喂给 SHA-256：解码出的字节与整串解码逐字节相同，因此**哈希值不变、已有缓存条目继续命中**，只是不再需要一整份原始字节常驻。新增回归测试校验「大图分片哈希 == 整串解码哈希」。

## 一并提供

本版本同时把 v2.1.0 的内存与稳定性改动作为可部署版本重发，便于一次性升级：

- 按 Model Service / Micro Agent 的 URL 附件总预算（`maxAttachmentBytes`，控制台可配，0/留空 = 不限制）；
- V8 堆上限对齐容器内存（读 cgroup 限额，`NODE_HEAP_PERCENT` 可调，`HYDROGEN_HEAP_AUTOSIZE=0` 关闭）；
- OCR 预处理分批（32 张 / 8 MiB 一次调用），峰值只与单批相关；
- Micro Agent 每阶段不再保留整份渲染后的 wire body；
- 图片缓存淘汰改用 keyset 游标，不再因 SQLite 变量上限中断整批写入；
- 后台异步路径加固：prune 定时器、Responses 任务 promise 与流式 relay 的记账失败不再导致进程退出。

## 升级与兼容性

- 无数据库变更，可直接在 2.1.0 之上替换镜像。
- OCR 缓存键（哈希前像）未变，已有缓存条目继续命中。
- 升级后建议硬刷新一次浏览器。
